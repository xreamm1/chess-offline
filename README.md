# Шахматы и русские шашки офлайн

Мобильная игра: полная Stockfish 19 WASM для шахмат, русские шашки 8×8, выбор имени или гостевой вход, друзья, приглашения, чат и поиск соперника через Firebase.

Сайт: https://xreamm1.github.io/chess-offline/

## Что добавлено в 4.0.0

- При входе — окно имени и кнопка «Войти как гость». Имя хранится на устройстве. Онлайн-профиль использует анонимный Firebase Auth; это не вход по паролю и не подтверждённая личность. При очистке данных браузера доступ к прежнему гостевому профилю и его друзьям теряется.
- Друзья по коду игрока, заявки и их принятие/отклонение, удаление друзей, приглашение в выбранную игру.
- Firebase Cloud Firestore передаёт ходы и чат. Прямое P2P-соединение для интернет-дуэлей больше не нужно; операторы МТС/Билайн не должны допускать входящие P2P-соединения. Нужен обычный доступ к Firebase.
- Поиск соперника работает отдельно для шахмат и русских шашек. Пара создаётся транзакцией, цвета распределяются случайно.
- Чат доступен участникам партии. Сообщения показываются как текст, длина до 300 символов, отправка не чаще раза в секунду. Чат партии также работает в ручном локальном WebRTC-режиме.
- Русские шашки: обязательное взятие, взятие назад, дальнобойные дамки, выбор полной серии, превращение в дамку во время боя. Ничья упрощена: три повторения или 30 тихих полуходов дамками; специальные турнирные лимиты по материалу не реализованы.
- Marcher RU — экспериментальный гибрид: настоящая NNUE Marcher WASM, русский поиск/правила Damka и точные таблицы окончаний до пяти фигур. Нейросеть исходно обучена на английских шашках; она добавляет ограниченную позиционную поправку к русской оценке. Это не переименование английского поиска и не новая обученная русская NNUE. Рейтинг адаптации не измерен; она не заявляется сильнейшей в мире. Подробности: `vendor/marcher-ru/README.md`.

## Firebase

Публичные параметры веб-приложения находятся в `firebase-config.json`. Для своего проекта замените их и выполните сборку. Сервисные ключи в клиент не добавляются.

В Firebase Console нужны Anonymous Auth, Cloud Firestore и правила из `firestore.rules`. Индексы описаны в `firestore.indexes.json`. Правила проверены с Auth/Firestore Emulator: заявки друзей, приглашения, подбор, обмен ходами, запрет чужого чтения и подмены автора чата.

При наличии Firebase CLI:

```sh
firebase login
firebase deploy --only firestore:rules,firestore:indexes
```

Это дружеская игра без рейтингового сервера и античита. Firestore ограничивает участников, очередность и атомарность ходов; легальность шахматных и шашечных ходов дополнительно проверяют клиенты. Данные партий, имён и чата сохраняются в Firebase. Квоты и хранение контролируются владельцем Firebase-проекта.

## Офлайн и GitHub Pages

Настройки Pages: **Settings → Pages → Deploy from a branch → main → / (root)**.

При первом шахматном анализе скачивается `stockfish19.wasm.gz` (около 79 МБ). Дождитесь завершения загрузки и анализа. Service Worker кэширует страницу и движок; шашечный движок и таблицы уже включены в страницу. После этого локальная игра и анализ доступны без сети. Браузер может удалить кэш при очистке данных или нехватке места. Друзьям, подбору и чату нужен интернет.

После обновления дождитесь активации Service Worker и перезагрузите страницу, если видна старая версия.

## Сборка и проверки

```sh
node build-offline.cjs
node test-rules.cjs
```

Сборка создаёт `index.html` для Pages и автономный `chess-offline.html` со встроенной полной SF19. Автономный файл больше лимита GitHub 100 МиБ и исключён из Git. Для изменений исходников шашечного адаптера:

```sh
npx --yes esbuild@0.25.11 damka-rules-entry.ts --bundle --format=iife --global-name=DamkaRules --minify --outfile=damka-rules.js
npx --yes esbuild@0.25.11 damka-worker-entry.ts --bundle --format=iife --minify --outfile=damka-worker.js
node build-offline.cjs
```

`test-rules.cjs` проверяет бой назад, обязательный бой, дальнобойных дамок, выбор короткой/длинной серии, превращение внутри серии, неизменность позиции и perft глубины 6 (37 986 листьев).

## Управление

Игра выбирается над доской. Семь нажатий по версии открывают «Лучший ход» и автоанализ. Настройки содержат GUI Stockfish, скорость анализа и режим памяти. При сбое полной SF19 памяти используется явно обозначенный резерв Lite. Marcher RU работает отдельно в Worker; при смене игры активный поиск отменяется.

## Сравнение и панели анализа (4.1.0)

В обычной партии соперником служит оригинальный Damka: NNUE-поправка Marcher отключена. «Лучший ход» продолжает использовать Marcher RU. В разделе бота доступен автоматический матч Marcher RU против Damka с одинаковым временем на ход (250/800/2000 мс) и выбором цветов. При смене движка таблица поиска очищается, чтобы оценки не смешивались.

В настройках есть отдельные «Stockfish вид» и «Marcher RU вид». Шашечная панель показывает каждый завершённый уровень поиска, оценку, кандидатов с границами, проверенное продолжение из TT, узлы/секунду, TT-попадания, вызовы NNUE и обращения к эндшпильным базам. Панель SF19 дополнена списком MultiPV-вариантов (1 или 3 в подсказке). Обе панели позволяют скачать журнал. Движки не выводят человеческие рассуждения и полное дерево всех узлов; интерфейс показывает только реальную измеренную телеметрию.

Damka проверен на начальной позиции глубины 5: ход, оценка и точное число узлов совпадают с немодифицированным оригиналом; вызовов Marcher NNUE — ноль. После поиска Marcher RU повторный поиск Damka даёт тот же результат.
