# Шахматы офлайн

Мобильные шахматы с полной Stockfish 19 WASM, локальной игрой, P2P-дуэлями через Trystero, QR-подключением и анализом ходов.

## GitHub Pages

В репозитории откройте **Settings → Pages → Deploy from a branch → main → / (root) → Save**.

Адрес: https://xreamm1.github.io/chess-offline/

При первом анализе загружается полный Stockfish (сжатый файл около 79 МБ). Дождитесь завершения загрузки и анализа. Service Worker сохраняет страницу и движок для последующего запуска без сети. Офлайн-кэш может быть удалён браузером при очистке данных или нехватке места. Онлайн-дуэлям требуется интернет; Trystero загружается с CDN только при нажатии поиска. Некоторые сети не допускают прямое P2P-соединение; TURN не настроен.

## Один автономный HTML

Установите Node.js и выполните в папке проекта:

```sh
node build-offline.cjs
```

Получится `chess-offline.html` со встроенным движком. Его можно открыть без установки и интернета. Этот файл больше лимита GitHub 100 МиБ, поэтому в репозитории опубликована версия Pages с отдельным сжатым WASM.

## Управление

Вкладка «С другом» → «Искать дуэль» для автоматического P2P-подбора. Семь нажатий по версии открывают подсказки и автоанализ. В настройках доступны GUI Stockfish, скорость анализа и режим памяти. При сбое полной сборки памяти используется явно обозначенный резерв SF19 Lite.
